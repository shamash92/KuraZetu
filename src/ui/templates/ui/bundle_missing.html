The frontend has not been built yet

Django is running, but there is no webpack bundle to serve. This is expected on a fresh setup: the backend and the frontend run in separate terminals, and the frontend has not completed its first build.

In a second terminal, run:

cd src/ui
pnpm install
pnpm run dev

Wait for webpack to report that it compiled successfully, then reload this page.

Full instructions are in the setup guide.
